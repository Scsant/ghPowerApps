# ghPowerApps

Repositório para projetar e desenvolver sistemas com Microsoft Power Apps, usando
o MCP Coauthoring para trabalhar com os aplicativos e o agente GitHub Copilot
para planejar, implementar, testar e documentar as mudanças.

## Objetivos

- Criar soluções Power Apps orientadas a requisitos e necessidades reais.
- Usar o MCP Coauthoring como interface de colaboração com os aplicativos e
  recursos Power Platform disponíveis no ambiente.
- Usar o agente GitHub Copilot para apoiar o ciclo de desenvolvimento, mantendo
  as alterações revisáveis e a documentação atualizada.
- Validar o comportamento da solução antes de disponibilizá-la.

## Fluxo de desenvolvimento

1. Descrever o problema, os usuários, os dados envolvidos e os critérios de
   aceitação.
2. Verificar com o MCP Coauthoring quais aplicativos e recursos estão
   disponíveis; confirmar o escopo antes de fazer alterações.
3. Pedir ao agente GitHub Copilot para propor um plano pequeno e revisar o plano
   antes da implementação.
4. Implementar a solução em etapas, preservando as convenções existentes e
   registrando decisões relevantes.
5. Testar os fluxos principais e os casos de erro, revisar as alterações e
   atualizar a documentação.

## Segurança e validação

- Nunca armazenar credenciais, tokens ou segredos no repositório.
- Não presumir acesso ou autorização para alterar aplicativos, dados ou
  ambientes; usar apenas os recursos disponibilizados e aprovados.
- Revisar as alterações produzidas pelo agente e validar a solução no ambiente
  Power Apps antes de publicá-la.

## Estado atual

Este repositório está no início e ainda não contém aplicativos, configuração do
MCP, ferramentas de build ou testes automatizados. As próximas contribuições
devem introduzir esses recursos conforme os requisitos da primeira solução,
documentando os pré-requisitos e os passos de validação necessários.
